# ADR-008 — Python 3.12 for the local environment

**Status:** accepted

**Context.** CLAUDE.md and the stack table pin Python 3.11, but 3.11 was not
installed on the development machine (only 3.12 and Anaconda 3.13 were present).

**Decision.** Build the venv with the already-installed **Python 3.12**. The
README states "3.11+", and every dependency (dbt-duckdb, Great Expectations,
scikit-learn, XGBoost, PySpark, Streamlit) fully supports 3.12.

**Consequences.** No Homebrew download on the disk-constrained SSD. Recreate the
venv with `python3.12 -m venv .venv`. Switch to 3.11 only if explicitly required.
